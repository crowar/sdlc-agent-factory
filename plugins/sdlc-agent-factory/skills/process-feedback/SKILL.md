# Process Feedback

Execute the reusable feedback workflow described in [the bundled workflow](workflow.md).

Treat the user's message as the feedback or backlog input and follow the prompt's prioritization, hotfix, implementation, testing, and reporting requirements. This skill exists so the workflow is available in Agent mode as well as Chat prompt-file mode.
